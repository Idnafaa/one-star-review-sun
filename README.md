A deadpan one-star review of an everyday essential: the sun. It rises uninvited every morning, burns skin, fades curtains, and has never once apologised. One star.

## Run it

```sh
python3 main.py
```

The program writes the review (114 characters) to `/output/entry.txt`, or to `./entry.txt` when run locally.
